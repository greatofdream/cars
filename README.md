# AckDrivingSim · 驾考科目二阿克曼驾驶模拟器

一个用 **Godot 4.7（Forward Plus）** 制作的 3D 低速驾驶模拟器，面向**驾考科目二**（倒车入库 / 侧方停车）的几何原理演示与短视频录制。车辆按真实教练车尺寸建模，库位尺寸按国家标准公式实时生成，并把阿克曼转向、内轮差、瞬时转向中心、后视镜视野等"考点几何"可视化出来。

> 目标不是做赛车游戏，而是把"为什么要看那个点、为什么镜里是梯形、内轮差从哪来"这些科目二背后的**几何道理**讲清楚。

---

## ✨ 特性

- **阿克曼运动学**：以后轴中心为原点、前轮按 Ackermann 联动，实时求解转弯半径与**瞬时转向中心（ICZ）**。
- **考点几何可视化**：转弯圆、内轮差带、四个车轮轨迹、ICZ 到各轮的半径线，一键显示/隐藏。
- **科目二场地**：`倒车入库`、`侧方停车` 库位按 **GB/T 30341-2013 附录 C** 公式由车辆自身尺寸实时生成。
- **踏板 + 挡位**：油门 / 刹车（刹车优先、怠速蠕行），自动挡 `P / R / N / D`。
- **三面后视镜**：中央 + 左右后视镜，各自独立 `SubViewport` 相机跟随车身；侧镜套**凸面桶形畸变 shader**，并可**调节朝向**（◀▶▲▼）。
- **驾驶位视角 + 座椅调节**：`V` 进入驾驶位，`I/K` 升降、`J/L` 前后调节坐姿。
- **多视角**：追尾 → 俯视（正交）→ 侧视（正交）循环切换。
- **程序化车辆外观**：CSG 轮拱（半圆柱挖空）、带 B 柱的梯形玻璃车厢（含 tumblehome 侧倾）、车门缝线与门槛线——全部代码生成，无外部模型。

---

## 🚀 运行

1. 安装 [Godot 4.7](https://godotengine.org/)（标准版即可，渲染后端 **Forward Plus**）。
2. 打开 Godot → **Import** → 选择本目录下的 `project.godot`。
3. 按 **F5** 运行（主场景 `scenes/main.tscn`，1280×720）。

---

## 🎮 操作

| 键 | 作用 |
|---|---|
| `W` / `↑` | 油门（当前挡位下加速） |
| `S` / `↓` | 刹车（任何挡位有效，踩死即停并保持） |
| `A` / `←`、`D` / `→` | 打方向（松手自动回正） |
| `Q` / `E` | 降 / 升挡（在 `P→R→N→D` 间循环） |
| `1` / `2` / `3` | 空场 / 倒车入库 / 侧方停车 |
| `C` | 视角循环：追尾 → 俯视(正交) → 侧视(正交) |
| `V` | 进入驾驶位视角 |
| `R` | 复位到本项目出生点（回到 `D` 挡） |
| `Space` | 显示 / 隐藏整个转弯圆 |
| `F1` | 开关调试信息 |
| `I` / `K` | 座椅升 / 降（驾驶位视角下） |
| `J` / `L` | 座椅后 / 前（驾驶位视角下） |

> 屏幕右侧的**菜单 Menu**、屏幕换挡器、后视镜朝向按钮、座椅滑块均可用鼠标操作。倒车入库时：先切到 `R` 挡，用 `W` 轻给油后退，全程用 `S` 控速。

## 📁 项目结构

```
.
├── project.godot              # Godot 工程配置（4.7 / Forward Plus）
├── scenes/main.tscn           # 唯一入口场景（运行时由脚本搭建全部节点）
├── scripts/
│   ├── main.gd                # 编排：HUD、菜单、视角、相机、输入、座椅
│   ├── ackermann_car.gd       # 阿克曼运动学 + 程序化车身/车厢/车门/轮拱
│   ├── course.gd              # 科目二库位（按国标公式实时生成）
│   ├── trajectory.gd          # 轨迹 / 内轮差 / 瞬时转向中心可视化
│   ├── mirror_rig.gd          # 三面后视镜（SubViewport + 跟随相机）
│   ├── pedals.gd              # 油门/刹车踏板 + 挡位显示
│   └── steering_wheel.gd      # 屏幕方向盘控件
├── shaders/mirror.gdshader    # 侧后视镜凸面（桶形畸变）
```

## 📐 尺寸与依据

- 车辆按常见 C1 教练车量级调好（轴距 2.51 m、宽 1.69 m、车长 4.41 m），故 `course.gd` 生成的库位即为真实考场比例。
- 库位/车位公式来源：**GB/T 30341-2013《机动车驾驶员培训教练场技术要求》附录 C**；评判规则参考 **GA/T 1026-2012**。公式在 `scripts/course.gd` 中按车辆自身尺寸实时实现。
